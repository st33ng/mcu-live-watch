# Code of Conduct

## Our commitment

This project is maintained in the open: issues, pull requests and discussions are welcome from
anyone, regardless of experience level, background or the toolchain they use.

## Expected behaviour

- Be concrete. "It does not work" is a starting point, not a bug report — say what you ran, what you
  expected and what happened instead.
- Critique the code and the design, not the person who wrote them.
- Assume the other side has information you do not. A hardware or IDE detail that looks obvious to
  you may be unreachable for someone else.
- Accept that a maintainer may decline a change. The reasons will be given.

## Unacceptable behaviour

- Personal attacks, insults, or dismissive remarks about someone's skill or equipment.
- Harassment of any kind, in issues, pull requests or private messages.
- Publishing someone's private information without permission.
- Sustained disruption of technical discussion.

## Scope

This code applies to the repository (issues, pull requests, discussions) and to any space where
someone is representing the project.

## Enforcement

Report a problem to the maintainer listed in `plugin.xml` / the repository owner profile. Reports are
read and handled privately. Responses range from a warning to a permanent ban, depending on severity
and repetition.
